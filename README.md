# Shopping NEW

Shopping 3D de moda no navegador (Three.js, sem build). Lojas: VANTRA, ATELIÊ, LE FERRI, NEW WEAR, NEW LAB, Central de Vendas.

## Começar com o Claude Code (mais fácil)

1. Instale o [Claude Code](https://claude.com/claude-code).
2. Clone este repo e o **MUNDO-MEX** (pasta `shared/personagem`) lado a lado — detalhes em `CLAUDE.md`.
3. Abra o Claude Code dentro de `shopping-3d` e peça o que quiser mudar. Ele lê o `CLAUDE.md` sozinho (mapa dos arquivos, regras, pendências) e já começa.

## Rodar

Sirva a pasta pai com `npx serve` (ou `python -m http.server 8099`) e abra `/shopping-3d/index.html`.
